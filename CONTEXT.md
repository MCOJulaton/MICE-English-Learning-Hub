# English Learning Hub: project map

Read this first. Open other files only when the task needs them.

## What this is
A static, multi-course website for the user's English classes at Phuket Rajabhat University. No build step. Hosted on Vercel (auto-deploys on every push to `main`). The Hobby plan's deployment storage is almost full, so avoid committing large files (audio, images, PDFs) and avoid commits that only change `_deliverables`.

## Where things are
| Path | What it holds |
|---|---|
| `courses/mice/`, `courses/wellness/`, `courses/communication/`, `courses/business-communication/` | One folder per course. Units in `unit-N/`. |
| `courses/writing/` | Principles of English Writing: all 15 units are built (2026-10-23), phone-first, one page per unit. A shared engine `js/lesson.js` draws every unit; each `unit-N/js/data.js` holds that unit's content and answers (step types: learn, choose, pick, order, plan, yourturn; cover and exit check are automatic). `css/lesson.css` is the shared style, `writing-theme.css` the indigo palette on the hub's fonts. Photos (AI-generated, `assets/images/pow-*.jpg`, only where they help understanding: Units 6, 7, 8, 9, 10) are set per step with `photo:{file,alt,caption}` or `photos:[...]` in data.js. Every unit follows the same ADDIE and Bloom flow: warm-up recall (Remember), learn and model (Understand), analyze practice, apply practice, plan builder, your turn in the workbook (Create), exit check (Evaluate). Content comes from the workbook units and uses the workbook page numbers (placeholders such as `{p2}`, `{rules}`, `{peer}` are set in `lesson.js`; update them there if the workbook pages move). No teacher page and no student tracking: progress is saved only in the browser (localStorage `pow-unitN-v2`). The page checks practice answers, and the answers are in the page code (practice only, no sample essays or answer keys beyond the practice). NOT yet in `js/course-catalog.js`, so the Practice, Downloads and Assignments hubs do not list them. The student pages show no graded or practice labels (user's rule). `index.html` lists the units (set `open:true` per unit). The site, workbook and teacher edition all use the same unit numbers 1 to 15 (the midterm and final exam are not units). |

| `js/course-catalog.js` | The list of units shown on each course page. Add a new unit here. |

| `_deliverables/` | Printable Word and PDF files (exams, worksheets, scripts). Has its own `CONTEXT.md`. Not part of the website. |

## Rules
- American English for all text, spelling and voice settings.
- Anything students read: A1 level, simple, natural, no dashes.
- Group writing tasks are printed worksheets. The site gives instructions only.
- Teacher scripts are flowing notes, not a repeated Say/Ask/Answer template.
- Commit and push only when the user asks. Never commit answer keys or student data.
- More detail is in the memory notes (`MEMORY.md`), which load automatically. Read a memory file only if the task needs it. The `project_english_learning_hub.md` note is very long, so search it instead of reading it all.

Students open `quizzes/makeup.html#result`, type Student ID plus receipt code, and see it. Nothing shows before release; Take back deletes it. Rules text in `FULL_RULES_TEXT` includes the `makeupReleased` get rule.
